# Tool scout

## Procedure
1. State the capability in one line and the experiment it serves.
2. Always include option 0: **do it manually / no-code** (Make, Tally, Airtable, Shopify, Google Sheets).
3. Find at least 3 real options. Check current docs and pricing pages (web fetch; Context7 for libraries). Check for an official MCP server.
4. Do a 30-minute spike on the top option when feasible: get the first real result.

## Compare
| Option | Fit for the experiment | Time to first result | Cost now / at 1k users | Unit cost per action | Lock-in / exit path | MCP available | Risks |
|---|---|---|---|---|---|---|---|

## Rules
- Pricing and API terms change: give the date you checked and the source link.
- Prefer free tiers and usage-based pricing pre-PMF. Avoid annual commitments.
- Flag terms that block the use case (commercial use, data retention, image rights, rate limits).
- Recommend one, say what would make you switch.
- Add confirmed good tools to the venture's `stack.md` with the date.
